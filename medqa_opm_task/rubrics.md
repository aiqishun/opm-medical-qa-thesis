总分 100 分。评分以专业判断和实际研究结果为主；文件命名、文字表述等形式问题只作小额扣分，不设置整题零分条件。采用不同但合理的方法，只要达到同等研究目标，应获得同等评价。

公式指标按照隐藏 Ground Truth 统一计算。设金标心血管正例集合为 P：
⚬	Precision = TP / (TP + FP)；
⚬	Recall = TP / (TP + FN)；
⚬	F1 = 2TP / (2TP + FP + FN)；
⚬	模型没有预测正例时，Precision 和 F1 记为 0。

一、数据与结果映射审计（15 分）
子项	分值	评分要点
1.1 ID 映射与对齐	5	JSONL、CSV 及历史结果间 ID 稳定对齐；别名（如 id / question_id）统一处理。
1.2 重复与冲突检测	4	成功识别重复题及矛盾参考；冲突被有效隔离并记录，而非静默覆盖。
1.3 字段异常值处理	3	缺字段、非法值（如非布尔值）被单独报告并保留原始位置。
1.4 处理记录可追溯	3	所有排除、纠正动作均有依据，且能回溯至原始 ID 与具体位置。
二、心血管主题专业判定（25 分）
子项	分值	评分要点
2.1 隐藏测试集 F1	20	依细化阶梯表自动计分；无正例预测时记 0 分。
2.2 主要考点识别	2	准确区分主要诊断/处置与既往史、危险因素、否定信息。
2.3 背景信息剥离	1.5	未将仅作为背景的心血管病史、胸痛等诱发因素误判为正例。

三、数据契约与文本处理（15 分）
子项	分值	评分要点
3.1 契约格式遵循	4	严格遵守 JSON Schema 定义的键值结构，未发生类型错误（如布尔值转字符串）。
3.2 短语抽取覆盖度	4	实际调用抽取方法，结果能充分覆盖主要考点。
3.3 语境角色识别	4	准确区分考点、既往史、危险因素等五类语境，并标注角色。
3.4 闭环与依据保留	3	抽取结果实际参与了主题判定（非仅打印）；每题保留原文位置供复核回溯。
四、OPM 结构与语义审计（25 分）
子项	分值	评分要点
4.1 OPL 语法规范	5	严格遵循 OPL 状态声明语法（... can be ... State ... is initial.），未输出散文。
4.2 主题一致性	6	OPM 主题与题目考点一致；未将通用常识强加为特定病例事实。
4.3 节点概念合理性	5	Object/Process/State 节点类型使用正确，命名符合医学专业语境。
4.4 关系方向与连续性	5	关系指向符合题干逻辑，解释路径能从结构化医学信息中连续追溯。
4.5 出处记录与验证	4	每题记录 OPM 元素来源依据，人工复核时可逐题对照检验。

5.4 结论与证据一致性	3	结论基于数据，未过度宣称未经严谨交叉验证的改进方法具备绝对优势。

专业 Score Cap（分数封顶）
Score cap 仅在发现明显违规证据时触发（不因规则方法或格式轻微差异触发）：
⚬	分类仅依赖关键词出现，未实际处理主要考点和语境角色：总分最高 70 分。
⚬	大量复用与当前题目无关的模板图，却将其作为有效医学解释：总分最高 70 分。
⚬	未实际运行数据处理，只提交纯文字分析或预写假结果：总分最高 60 分。
⚬	经核实存在编造数据、图关系或捏造实验结果：总分最高 50 分。
Grader 兼容与复核指南
	1.	鲁棒性要求：自动评分需容忍空行，统一标准化布尔值及 ID 别名。
	2.	错误隔离：非法字段和值必须单独记录报错，不可静默覆盖。
	3.	分母固定：缺失预测按固定金标总数计算（防“漏题刷分”），多余未知 ID 不计入。
	4.	人工裁决：图语义、同义词替代、边界病例由人工复核裁定。
	5.	一致性校验：每份 submission 独立评分两次，客观指标须绝对一致；主观维度分差超 2 分或总分超 5 分即进入人工复议并留存裁决依据。
