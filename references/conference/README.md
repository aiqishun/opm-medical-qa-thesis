# 继承的会议研究材料

这些文件从迁移时的原工作目录复制，供毕业论文追溯与比较。
其中论文文件可能包含会后修改，尚未核实为最终发表版本。
本目录不表示当前工作已经产生新的毕业论文成果。

- `project_README.md`：原项目说明。
- `paper/`：原工作目录中的论文材料。
- `project_report.md`：原项目报告。
- `results/`：原 Git 仓库跟踪的自动图评价结果。
- `DELIVERY_AUDIT.md`：原交付包审计记录，不代表已覆盖新增发现。
- `original_delivery_MANIFEST.sha256`：原交付包的文件清单，仅用于历史追溯。

完整原工作目录和其他批量结果在本地迁移快照中。
新源码的 `medqa_opm_task/` 补入了原有推理脚本及其依赖数据，
其后续构建将生成新的交付清单。
